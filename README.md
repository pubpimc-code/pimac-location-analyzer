# 🍕 피맥 출점 분석 시스템 v1.0

## 프로젝트 소개

피맥 출점 분석 시스템은 경쟁 브랜드의 위치를 분석하여 신규 출점 후보지를 추천하는 프로그램입니다.

## 주요 기능

- 경쟁 브랜드 지도 표시
- 브랜드별 색상 구분
- 경쟁도 분석
- 반경(300m / 500m / 1km) 분석
- Heat Map
- 추천 출점 지역
- 상권 분석

## 개발 단계

### ✅ Phase 1
- 프로젝트 생성
- 지도 표시
- 브랜드 표시

### ⏳ Phase 2
- Heat Map
- 경쟁도 분석

### ⏳ Phase 3
- AI 추천
- 상권 분석
- PDF 보고서
